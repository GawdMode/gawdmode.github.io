GAWDMODE GITHUB PAGES — UPLOAD GUIDE

1. Go to https://github.com/new
2. Repository name: gawdmode.github.io
3. Set visibility to Public.
4. Do NOT add a README, .gitignore, or license during creation.
5. Click "Create repository".

UPLOAD:
6. On the empty repository page, choose "uploading an existing file".
7. Open the "gawdmode-site" folder from this package.
8. Drag EVERYTHING inside it onto GitHub:
   - assets/
   - .nojekyll
   - index.html
   - mods.json
   - README.md
   - script.js
   - style.css
9. Click "Commit changes".

ENABLE GITHUB PAGES:
10. Open repository Settings.
11. In the left sidebar choose Pages.
12. Under "Build and deployment":
    Source: Deploy from a branch
    Branch: main
    Folder: / (root)
13. Click Save.

Your site address:
https://gawdmode.github.io/

IMPORTANT:
Upload the CONTENTS of the folder, not the outer gawdmode-site folder itself.
index.html must appear at the top/root of the repository.
