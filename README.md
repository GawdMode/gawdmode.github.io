# GawdMode Gen1Recomp Mod Hub

Source for https://gawdmode.github.io/

## Updating the site

Most updates only require editing `mods.json` or replacing images in `assets/`.

## Publishing

GitHub Pages should be configured to deploy from the `main` branch and `/ (root)` folder.

This site is intentionally plain HTML/CSS/JavaScript so it can be maintained without a build system.
